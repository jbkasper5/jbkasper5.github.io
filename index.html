featured project

      
rpos — a bare-metal OS for the Raspberry Pi 4B

      
A hobby kernel written from scratch in C and AArch64 assembly. No Linux, no bootloader shortcuts — it comes up at EL3, brings up the MMU, and runs its own userland.

    


    

      

        

          

            CAArch64 asmARMv8-ABCM2711
          

          
rpos

          
v0.3.0-dev · ~14k LOC · single-author

          
Boots on real hardware and QEMU. Implements a 4-level virtual memory system, a buddy + slab allocator, a preemptive scheduler, copy-on-write fork(), an ext4 driver over EMMC, and an ELF loader that runs real user binaries through a small syscall layer.

          
Debuggable over JTAG with J-Link + OpenOCD + GDB against a running board — the same trace scrolling behind this page.

rtscheduler — real-time scheduling on bare RISC-V

CRISC-V asmQEMURMS / EDF
